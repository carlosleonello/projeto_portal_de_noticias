# 📰 Portal de Notícias — Tech News

Projeto de estudo desenvolvido com a [Rocketseat](https://www.rocketseat.com.br/) para praticar HTML e CSS a partir de um layout de referência no Figma.

O projeto apresenta a interface de um portal de notícias sobre tecnologia, com destaques sobre inteligência artificial, robótica, realidade virtual e outros temas.

## 💻 Sobre o projeto

A página está organizada em:

- Cabeçalho com logotipo e navegação por categorias.
- Área de destaques com uma notícia principal e quatro notícias menores.
- Seção de matérias mais lidas da semana.
- Lista de destaques sobre inteligência artificial.
- Barra lateral com anúncio e notícias complementares.

O foco desta etapa foi construir e estilizar o layout para computador. Os elementos de menu e busca são visuais, e os links de navegação ainda não levam a páginas de notícias.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- CSS Grid
- Google Fonts — Archivo

## 📚 Aprendizados

Durante o desenvolvimento, pratiquei:

- Organização do conteúdo com elementos como `header`, `nav`, `main`, `section`, `article` e `aside`.
- Criação de layouts com CSS Grid, utilizando colunas, espaçamentos e áreas nomeadas.
- Uso de variáveis CSS para padronizar cores e tipografia.
- Posicionamento de textos sobre imagens e aplicação de gradientes.
- Criação de classes utilitárias para reutilizar estilos.
- Separação do CSS em arquivos conforme a responsabilidade de cada parte da página.

## ▶️ Como visualizar

1. Baixe o projeto pelo botão **Code → Download ZIP** deste repositório.
2. Extraia os arquivos para uma pasta no seu computador.
3. Abra o arquivo `index.html` no navegador.

Se utilizar o VS Code com a extensão Live Server, você também pode abrir o projeto pela opção **Open with Live Server**.
